# Little Market

A responsive mini e-commerce storefront built with React, React Router, and Redux Toolkit.

## Run locally

```sh
npm install
npm run dev
```

## Features

- Home, products, cart, about, checkout, order confirmation, and not-found pages
- Redux Toolkit cart with quantity controls, totals, and localStorage persistence
- Product search and category filters
- Responsive layout and add-to-cart feedback

Product images and web fonts load from external URLs.
